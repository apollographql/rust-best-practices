# Rust Best Practices for Coding Agents

Start with [llms.txt](llms.txt): a compact Rust decision guide and router to focused chapters. The chapters expand design choices, testing strategies, and lifecycle contracts. Agents fetching over HTTP can use the [raw file](https://raw.githubusercontent.com/apollographql/rust-best-practices/main/llms.txt).

The [compiled examples](examples/) show perimeter parsing into domain types, required constructors, existing types as state, and deferred initialization. [Collaboration](collaboration.md) sets when agents stop for human steering. [Contribution guidance](CONTRIBUTING.md) covers changes to the guide.
